Как будет работать монитор

После подключения FaucetPay монитор будет периодически проверять историю поступлений, обнаруживать новые транзакции и воспроизводить звук WebMoney. При первом запуске существующие транзакции не должны вызывать звуковые уведомления.

Важно: одной страницы GitHub Pages недостаточно для автоматического доступа к авторизованной сессии FaucetPay. Подключение API проверим отдельно, не передавая пароль или секретные данные на GitHub Pages.
